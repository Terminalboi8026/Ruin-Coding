# Ruin Programming Language

An expressive coding language designed for everything.

## Overview

Ruin is a simple, elegant programming language that aims to provide a clean syntax for general-purpose programming. Whether you're writing scripts, building applications, or learning programming concepts, Ruin offers an intuitive environment.

## Features

- 🚀 Simple and clean syntax
- 📝 Easy to learn and read
- 🔧 General-purpose programming
- 🎯 Support for functions and control flow
- 📦 Built-in data types (numbers, strings, booleans, arrays, objects)

## Quick Start

### Running a Ruin Program

```bash
python3 src/ruin.py examples/hello_world.ruin
```

### Example Code

```ruin
// Hello World
print("Hello, World!");

// Functions
func greet(name) {
    print("Hello, " + name + "!");
}

greet("Ruin");
```
