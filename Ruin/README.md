Ruin Language (Beta)

What this is
- A minimal VS Code TextMate grammar for the Ruin Operator language.
- Example file: `examples/demo.ruin` demonstrating commands, properties, nesting, strings, and a custom call.

Test in VS Code
1. Open this folder in VS Code:

```bash
code "." 
```

2. Press `F5` to launch the Extension Development Host.
3. In the new host window, open `examples/demo.ruin` to inspect syntax highlighting.

Notes & next steps
- To change the grammar, edit `syntaxes/ruin.tmLanguage.json` and reload the Extension Development Host.
- I can add more examples, adjust scopes, or make keywords case-insensitive — tell me which.
