What is Ruin?

Ruin is a structured, visual-first programming language designed for clarity and unambiguous execution. Every command, property, and value is explicitly categorized — no implicit behavior, no hidden surprises. Whether you're building games, websites, or complex systems, Ruin's clean syntax makes your code readable and maintainable.

Core Features

🎯 Explicit by Design

No ambiguous properties or implicit conversions. Every value and category is clearly specified using property categories and separators.

📐 Visual Structure

Nesting with parentheses, indentation with dots, and clear command terminators (#) make code structure mirror execution flow.

⚡ Simple Syntax

Commands end with #, properties start with ., and values are separated by , — that's it.

🔧 Powerful Operators

Math constants (e, Tau, Pi, i), percentage values, modulo, and standard operators with clear precedence.

🎮 Built for Games

Control input, manipulate vectors, set entity properties — all with readable, structured commands like Control(), Vec(), and Goto().

🌐 Universal

From game engines to web backends, Ruin adapts to any domain with custom commands and property types.

Syntax at a Glance

Here's what Ruin code looks like:

Val(
   .Input: 1
   .output: Val(
      .type: x;vec/player ,Value: x + 10)
)#

Control(
   .Input: W
   .Action: Move(
      .Type: x;Vec/player ,Value: x + 5
   )
)#

Key Rules:

  • Commands are capitalized: Val(), Control(), Custom()
  • Every command ends with #
  • . enters a property level, , continues at the same level
  • Property categories explicit: Type: x;Vec/player (property;category/target)
  • Custom commands: define with Custom(.Name: Foo ...), call with 'Foo(...)

Get Started

Install the VS Code Extension

Get syntax highlighting, file icons, and language support for Ruin in Visual Studio Code:

code --install-extension ruin-language-0.0.3.vsix

Or search for "Ruin Language" in the VS Code Marketplace (coming soon).

Write Your First Ruin Program

Create a hello.ruin file and start coding:

Val(.Type: text//console_print ,Value: "Hello, Ruin!")#
